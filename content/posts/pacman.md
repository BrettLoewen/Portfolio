I wanted to create a game without relying on a full game engine. I also wanted to build more experience with Python, so I chose the Pygame library as my "engine" for this project. Pygame gave me the tools I needed to make a game while still requiring me to be more hands-on than a normal game engine.

For the game, I chose to recreate the classic _Pac-Man_ arcade game because I thought that basing my work on an existing game would let me focus more on learning the new tools and system I was using. While not an exact replica, I was able to create the core features of controlling Pac-Man as he moves around the level, collects pellets, avoids ghosts, and uses power pellets to defeat the ghosts when necessary.
