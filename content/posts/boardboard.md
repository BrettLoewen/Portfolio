_Board Board_ is a digital whiteboard web app where users can create and manage notes, shapes, and drawings to organize their thoughts, brainstorm, and collaborate. The app is largely inspired by [Milanote](https://milanote.com/) and [FigJam](https://www.figma.com/figjam/).

I decided that I wanted to use Vue for this project because I already had experience with React and wanted to try a different framework.

To test out my idea and learn what it would take to develop a Vue app, I made a prototype where I could safely do my R&D without having to worry about maintainability or security. I built a simple version of the whiteboard, where a user can place various cards onto a canvas and move them around. With the concept proven and a lot learned about development with Vue, I was ready to start on the actual web app.

As of writing, I am still working on this project. I have successfully hooked up the app to a Supabase backend and implemented authentication. I am currently working on the app's dashboard and plan to move to the whiteboard implementation shortly.
