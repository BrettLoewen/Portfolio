_FeedFlo_ provides sensors that monitor animal feed pipes to keep farmers informed about their barns and ensure any issues are discovered and addressed quickly to keep the animals healthy.

My primay roles at _FeedFlo_ were to create and improve features for the web front-end and create a mobile app equivalent to the web front-end. Since I had no prior experience in web or mobile development, I was required to learn a lot and learn it quickly. I developed a strong understanding of JavaScript and React as I worked independently on, and took ownership of, several features for their web front-end’s alert dashboard including adding date-based paging, URL embedded filters for easy copying, and clickable graph elements. I built my understanding of mobile software development while working to build the foundation for _FeedFlo_’s mobile app. I also built skills with Git, GitHub, and SQL throughout my time at _FeedFlo_.

My work experience provided me with transferable skills in both self-directed and team-oriented work styles, as I coordinated with team members to build the apps together and integrate with the existing infrastructure of sensors, servers, and databases. I demonstrated flexibility and grew my appreciation for agile software development when the company’s primary direction shifted, requiring me to reprioritize my workload to overhaul how the database schema handles permissions and users to support a new use case.
